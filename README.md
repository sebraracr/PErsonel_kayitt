# 📋 Personel Kayıt Sistemi (PErsonel_kayitt)

Bu proje, personellerin bilgilerini dijital ortamda tutmak, yönetmek ve listelemek amacıyla geliştirilmiş bir **C# Windows Forms** uygulamasıdır. 

Bu çalışma, **Murat Yücedağ**'ın eğitim serileri takip edilerek, yazılım geliştirme süreçlerini ve veritabanı yönetimini öğrenmek amacıyla hazırlanmıştır.

## 🚀 Özellikler
* **Personel Kaydı:** Yeni personel bilgilerini sisteme ekleme.
* **Bilgi Güncelleme:** Mevcut personel verilerini düzenleme.
* **Personel Silme:** Kayıtlı personelleri sistemden kaldırma.
* **İstatistik Paneli:** Toplam personel sayısı, şehir çeşitliliği ve maaş analizleri gibi verileri görüntüleme.
* **SQL Veritabanı Entegrasyonu:** Verilerin ADO.NET kullanılarak MS SQL Server üzerinde güvenli bir şekilde saklanması.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C#
* **Platform:** .NET Framework / Windows Forms
* **Veritabanı:** Microsoft SQL Server
* **Eğitmen:** [Murat Yücedağ]
